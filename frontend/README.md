## Frontend

React (Vite) UI that provides the Feeder and Viewer components.

### Run locally

```bash
bun install
bun run dev
```

### Environment

- `VITE_API_BASE_URL` (default: `http://localhost:8000`)
- `VITE_WS_BACKEND_URL` (default: `ws://localhost:8000`)
- `VITE_CAMERA_WIDTH`, `VITE_CAMERA_HEIGHT`

### Tests

```bash
bun run test
```
